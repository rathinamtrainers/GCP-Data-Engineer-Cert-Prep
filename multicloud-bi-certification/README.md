## 🚀 Portfolio Projects

### [Project 1: GCP Weather Analytics Dashboard](portfolio/01-gcp-weather-dashboard/)
**Skills**: Power BI + GCP BigQuery integration, DAX, visualizations
**Description**: Connect to your existing GCP Weather ETL Pipeline data in BigQuery and create an interactive analytics dashboard.

**Key Features**:
- BigQuery connector setup
- 10+ visualizations (temperature trends, precipitation, forecasts)
- Advanced DAX measures (moving averages, YoY comparison)
- Mobile-responsive design

**Interview Value**: Demonstrates GCP integration (unique differentiator)

---

### [Project 2: Azure End-to-End ETL Pipeline](portfolio/02-azure-etl-pipeline/)
**Skills**: Azure Data Factory, Azure SQL DW, PolyBase, Power BI
**Description**: Build complete data pipeline from raw data to Power BI dashboard using Azure services.

**Architecture**:
```
Raw Data (CSV/JSON) → Azure Data Factory → Azure SQL DW → Power BI Dashboard
```

**Key Features**:
- ADF pipeline with multiple data sources
- PolyBase external tables
- Incremental data loading
- Scheduled refresh automation

**Interview Value**: Shows end-to-end Azure data engineering skills

---

### [Project 3: Embedded Analytics Web Application](portfolio/03-embedded-web-app/)
**Skills**: Power BI Embedded, JavaScript, authentication, web development
**Description**: Create a web application with embedded Power BI reports and interactive filtering.

**Tech Stack**:
- Frontend: HTML/JavaScript
- Backend: Node.js or Python Flask
- Authentication: Azure AD Service Principal
- Embedded: Power BI JavaScript SDK

**Key Features**:
- Embed token generation
- Dynamic report filtering
- User-specific data (RLS)
- Custom themes and styling

**Interview Value**: Demonstrates application integration expertise

---

### [Project 4: Salesforce Integrated Dashboard](portfolio/04-salesforce-integration/)
**Skills**: Salesforce (Visualforce, Apex), Power BI Embedded, JavaScript
**Description**: Embed Power BI reports in Salesforce with context-aware filtering.

**Key Components**:
- Visualforce Page with embedded Power BI report
- Apex Controller for authentication
- JavaScript for passing Salesforce context to Power BI
- Dynamic filtering based on Salesforce user/account

**Interview Value**: Addresses specific job requirement (Salesforce integration)

---

### [Project 5: Automated Reporting System](portfolio/05-automated-reporting/)
**Skills**: Power BI REST API, Python/PowerShell, scheduling, automation
**Description**: Programmatically manage Power BI reports, automate deployment, and distribute reports.

**Features**:
- Automated dataset refresh
- Programmatic report deployment
- Scheduled report distribution (email/export)
- Workspace management automation
- Error monitoring and alerts

**Interview Value**: Shows API automation and DevOps mindset

## 📊 Daily Time Allocation (8-12 hours/day)

### Typical Day Structure:
- **3-4 hours**: Tutorial modules (reading, watching videos, note-taking)
- **4-6 hours**: Hands-on practice (building dashboards, writing code)
- **1-2 hours**: Projects (portfolio development)
- **0.5-1 hour**: Review, documentation, preparing for next day

### Study Tips:
1. **Start with modules in sequence** - Don't skip ahead
2. **Type every code example** - Don't copy-paste
3. **Build projects incrementally** - Add features daily
4. **Document your learning** - Keep notes for interview prep
5. **Test everything** - Break things and fix them (best learning)
6. **Review previous day** - 15 mins each morning
